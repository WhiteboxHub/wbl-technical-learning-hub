# Daily Report & Weekly Rollup Templates

The Quiz & Assessment Agent (or your ChatGPT/coding agent at the end of a study session) generates this fixed block so your instructor can scan reports quickly and address weak areas in the next class.

## Daily Report Template
```markdown
DAILY REPORT - [Candidate name] - [Date]
Program: Whitebox Learning - MySQL & Relational Databases - Module __

Session covered:
- Class / Module studied: [Module N - Title] - attended [Yes / Self-paced]

Labs & SQL work:
- [Lab / Exercise name] - [Completed / Partial / Not started]
- SQL queries written / reviewed today: [one line, or "None"]

Quiz:
- Topics tested: [list of beats/topics]
- Score: [ __ / 8 ]
- Weak areas: [specific topics, in priority order]
- Strong areas: [topics answered well]

Open questions for the instructor:
1. [Question - or "None today"]
2. [Question]

Help I need next: [one line - Tutor, Practice, SQL Coach, or "None"]
```

## Weekly Rollup Prompt (End of Week)
Paste your Daily Reports and Candidate State into your Quiz Agent and ask:
> "Here are my Daily Reports and my Candidate State. Produce my WEEKLY ROLLUP: modules completed, labs completed vs set, my quiz scores in order, weak areas that repeated more than once, weak areas now cleared, and my top 3 priorities next. Then give me my UPDATED CANDIDATE STATE."
