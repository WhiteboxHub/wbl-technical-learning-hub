# Class-Day Quickstart Checklist

Follow this checklist before starting the **Software Design, Architecture, SDLC & Agile (JIRA)** session.

---

## Tooling & Architecture Philosophy
- **100% Cloud-First & Zero-Docker**: This course uses live **Atlassian Jira Cloud** directly in your web browser. No Docker containers, no local database installations, and no local backend servers are required on student laptops.
- **Story Anchor**: Building a House (Blueprints $\rightarrow$ Foundation $\rightarrow$ Utility Tiers $\rightarrow$ Subcontractor Standups $\rightarrow$ Jira Sprints).

---

## Step 1: Verify Directory and Session
1. Ensure your terminal or workspace is in:
   ```bash
   cd "wbl-technical-learning-hub/software-design-sdlc"
   ```
2. Verify that `.claude/skills/` (Claude Code) and `.agents/skills/` (Antigravity / Gemini CLI) are present:
   - `setup-sdlc-class` — Automated pre-flight environment verification
   - `teach-sdlc-class` — Step-by-step in-class teaching co-pilot
   - `setup-candidate` — Candidate Jira Cloud onboarding & login steps
   - `learn-sdlc` — Self-paced beat-by-beat candidate tutor
   - `practice-sdlc` — Post-class candidate learning, mock interviews, and exercises
3. If using an AI session, start a fresh conversation so the skills are indexed.

---

## Step 2: Open Atlassian Jira Cloud & Curriculum
1. Open Atlassian Jira Cloud ([https://atlassian.net](https://atlassian.net) or [https://www.atlassian.com/software/jira/free](https://www.atlassian.com/software/jira/free)) in your web browser.
2. Verify your free Scrum project (`HOUSE`) and live dashboard are accessible.
3. Have the course curriculum ready on your screen.

---

## Step 3: Run the Pre-Flight Verification
In chat, type:
```text
set up the class
```
Look for:
```
All 5 curriculum modules verified.
All 4 AI skills verified.
All 6 prompt files + README verified.
All documentation verified.
STATUS: READY TO TEACH
```

---

## Step 4: Initiate Teaching Session with the AI Co-Pilot
1. In chat, type:
   ```text
   teach module 1
   ```
2. When asked:
   > *"Is your screen shared with candidates?"*
   - Answer **Yes** if candidates can see your chat screen (answers stay hidden).
   - Answer **No** if only you can see the terminal/chat.

---

## Step 5: During Class Quick Reference
- Type `next` to move to the next beat.
- Type `answer` to reveal question answers.
- Type `repeat` if candidates need another pass.
- Type `jump 1.3` to jump directly to any beat.
- Type `end` at the end of the module to launch the hands-on lab.

---

## Step 6: Post-Class Candidate Study & Interview Practice
After class ends, candidates can practice in chat anytime by typing:
- `interview questions on module 1` — Practice senior-level architectural interview challenges
- `mock interview` — Comprehensive SDLC, Architecture, and Agile interview
- `quiz me on module N` — Socratic concept checks with progressive hints
- `check my user story` — Audits candidate stories against the 6 INVEST principles
- `help with the exercise` — Guided feedback on blueprints and Jira sprints
